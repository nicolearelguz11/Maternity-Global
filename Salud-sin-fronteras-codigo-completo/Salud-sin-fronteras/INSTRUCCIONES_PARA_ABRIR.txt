SALUD SIN FRONTERAS — CÓMO ABRIR EL SITIO

OPCIÓN 1: abrir la versión publicada
https://salud-sin-fronteras.xctfzbjrmb.chatgpt.site

OPCIÓN 2: abrir el código en tu computadora

1. Descomprime el archivo ZIP.
2. Instala Node.js 22 o una versión posterior desde:
   https://nodejs.org/
3. Abre una terminal dentro de la carpeta descomprimida.
4. Ejecuta:

   npm install
   npm run dev

5. La terminal mostrará una dirección local, normalmente:
   http://localhost:5173

6. Copia esa dirección y ábrela en Chrome, Edge o Safari.

ARCHIVOS PRINCIPALES PARA EDITAR

- app/page.tsx: contenido, guías, calculadoras y funcionamiento.
- app/globals.css: colores, tamaños, tarjetas y diseño.
- app/layout.tsx: título y configuración general.

Si utilizas Visual Studio Code:

1. Abre Visual Studio Code.
2. Selecciona Archivo > Abrir carpeta.
3. Elige la carpeta descomprimida.
4. Abre Terminal > Nueva terminal.
5. Ejecuta npm install y después npm run dev.

Nota: las calculadoras son orientativas y el contenido del sitio no sustituye
una valoración médica individual.
